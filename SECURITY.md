# Security Policy

## Reporting Security Issues

MigrationPilot is a static analysis tool designed to inspect SQL scripts offline. It does not execute SQL against live databases.

If you believe you have discovered a vulnerability in MigrationPilot's parsing, AST processing, or CLI execution:

1. Do NOT open a public GitHub issue.
2. Email security concerns privately to security@migrationpilot.dev or submit via GitHub Private Vulnerability Reporting.
3. Include reproducible proof-of-concept SQL scripts.
